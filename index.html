Co-op party

Roll a whole party of the same faction and share one code with your friends: it carries the rolls, the era, the allowed races / classes and the world seed, so everyone sees the same thing. In game, player 1 types .coop create and the others .coop join with the 6 letter code it gives, so you all start in the same place.
